# Tower of Hanoi (C# Windows Forms)

This project is a graphical simulation of the classic Tower of Hanoi puzzle, built using C# and Windows Forms. It features an interactive drag-and-drop interface, allowing users to move disks between rods while following the puzzle's rules.

## Features
- Visual representation of three rods and ten disks
- Drag and drop disks between rods
- Enforces Tower of Hanoi rules (cannot place larger disk on smaller disk)
- Real-time updates and smooth graphics

## How to Run
1. Open the project in Visual Studio.
2. Build and run the solution.
3. The application window will display the rods and disks. Use your mouse to drag the top disk from one rod to another.

## Gameplay Instructions
- Only the top disk of any rod can be moved.
- Disks can only be placed on empty rods or on top of a larger disk.
- The goal is to move all disks from the first rod to another rod, following the rules.
